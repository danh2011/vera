# Vera

Your AI. Your data. Your hardware. A lightweight, local-first personal assistant: a React web app, a single Node.js/Fastify backend, SQLite storage, optional Gemini, a privacy gateway that blocks banking and credential data from reaching any cloud model, and an App Store-style Integrations catalogue of 50 tools.
